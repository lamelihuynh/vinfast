ProductSearch::buildQuery (filter + sort)

~5h · Phụ thuộc: T1 luồng đọc, T2-07 · MONGO DDL

Chuyển Product::buildCatalogFilters (dòng 30-68) và phần sort trong filterPaginated (dòng 357-363), filterAll (dòng 384-393) thành filter và sort của MongoDB, cùng ngữ nghĩa với bản cũ.

Các bước

  1. Luôn có isActive: true (cũ: is_active = 1).
  2. search: cũ là name LIKE '%q%' (không phân biệt hoa thường do collation utf8mb4_unicode_ci). Bản mới mặc định dùng new Regex(preg_quote($q), 'i') trên name; chế độ text thêm ở T2-11.
  3. category_id: categoryID cùng kiểu với lúc T1 migrate (ép kiểu một chỗ).
  4. price_min/price_max trên basePrice; giữ quy tắc cũ !empty() (giá trị 0 bị bỏ qua).
  5. range trên attributes.rangeKm: lt200 → {$gt:0,$lt:200}, 200-400 → {$gte:200,$lte:400}, gt400 → {$gt:400}. Document thiếu field không khớp, giống NULL bên SQL. Thay hẳn cho REGEXP_SUBSTR ở dòng 56.
  6. Sort: price_asc → basePrice:1, price_desc → basePrice:-1, còn lại → createdAt:-1. Thêm _id làm khóa phụ để phân trang ổn định.

final class ProductSearch
{
    public static function buildQuery(array $filters): array
    {
        $f = ['isActive' => true];
        if (!empty($filters['search'])) {
            $f['name'] = new MongoDB\BSON\Regex(preg_quote((string)$filters['search'], '/'), 'i');
        }
        if (!empty($filters['category_id'])) $f['categoryID'] = (int)$filters['category_id']; // DDL
        $price = [];
        if (!empty($filters['price_min'])) $price['$gte'] = (float)$filters['price_min'];
        if (!empty($filters['price_max'])) $price['$lte'] = (float)$filters['price_max'];
        if ($price) $f['basePrice'] = $price;
        $ranges = ['lt200' => ['$gt' => 0, '$lt' => 200],
                   '200-400' => ['$gte' => 200, '$lte' => 400],
                   'gt400' => ['$gt' => 400]];
        if (isset($ranges[$filters['range'] ?? ''])) $f['attributes.rangeKm'] = $ranges[$filters['range']];
        $sort = match ($filters['sort'] ?? 'default') {
            'price_asc'  => ['basePrice' => 1,  '_id' => 1],
            'price_desc' => ['basePrice' => -1, '_id' => -1],
            default      => ['createdAt' => -1, '_id' => -1],
        };
        return [$f, $sort];
    }
}

public static function paginate(array $filters = [], int $page = 1, int $perPage = 10): array
{
    [$f, $sort] = self::buildQuery($filters);
    $page = max(1, $page); $perPage = max(1, $perPage);
    $cur = Db::mongo()->products->find($f, [
        'sort' => $sort, 'skip' => ($page - 1) * $perPage, 'limit' => $perPage,
        'projection' => self::LIST_PROJECTION,
    ]);
    return array_map([Product::class, 'formatProduct'], $cur->toArray());
}

public static function set(int $userId, string $productId, ?string $variantId, bool $on): bool
{
    $pdo = Db::pg();
    $wid = self::ensureWishlistId($userId);
    if ($on) {
        $pdo->prepare('INSERT INTO wishlist_items (wishlist_id, product_id, variant_id)
                       VALUES (:w, :p, :v)
                       ON CONFLICT (wishlist_id, product_id, variant_id) DO NOTHING')
            ->execute([':w' => $wid, ':p' => $productId, ':v' => $variantId]);
    } else {
        $pdo->prepare('DELETE FROM wishlist_items
                        WHERE wishlist_id = :w AND product_id = :p
                          AND variant_id IS NOT DISTINCT FROM :v')
            ->execute([':w' => $wid, ':p' => $productId, ':v' => $variantId]);
    }
    return $on;
}
